完整遇敵/戰鬥流程：

遇敵前：
- move()或search()時，調用 \revbattle\calc_meetman_rate($data) 計算遇敵概率，將獲取到的遇敵率傳入discover()；
- 觸發遇敵時，調用 \revbattle\calc_hide_rate($data,$edata) 計算敵人躲避概率；
- 敵人未躲避成功時，調用 \revbattle\calc_active_rate($data,$edata) 計算先攻概率；
- 先攻敵人：調用 \revbattle\findenemy_rev($edata) 轉入先攻（可操作戰鬥界面）；
- 被敵人先攻：調用 \revcombat\rev_combat_prepare($edata,$data,0) 轉入戰鬥準備流程；

先攻（可操作戰鬥界面） findenemy_rev() ：
- 調用 init_battle_title($pdata,$edata,$ismeet) 初始化戰鬥標題（左側界面中間紅字）；
- 調用 init_battle_log($pdata,$edata,$ismeet) 初始化發現敵人時顯示的log；
- 調用 init_battle_rev($pdata,$edata,$ismeet) 將敵我雙方數據格式化處理後傳給界面顯示；
- 遍歷主視角技能組，初始化戰鬥技能；
	- 調用 get_skilltags($sk,'battle') 檢查技能是否帶有主動技標籤；
	- 調用 check_skill_unlock($sk,$pdata) 檢查技能是否滿足解鎖條件；
	- 調用 check_skill_cost($sk,$pdata) 檢查技能是否滿足消耗條件；
	
處理從界面傳回的戰鬥指令（攻擊、技能、逃跑） revbattle_prepare()：
- 執行動作前，主視角的 action 值為 'chase','pchase','dfight','cover' 中任一時，command 繼承 action 值；
- 從這一流程開始，可以將任意參數直接保存在$data(主視角數據)或$edata(敵人視角數據)數組內，這些參數在戰鬥結束前不會丟失；
- 根據主視角的 action 與 bid 判斷接下來的行動：
	- 'enemy', //遇敵時獲得 代表遭遇了敵人 bid為敵人id
	- 'corpse', //遭遇屍體或擊殺敵人獲得 bid為屍體id；重載界面時，如果有此標記會顯示發現屍體
	- 'pacorpse', //通過反擊擊殺敵人獲得 bid為屍體idd；重載界面時，如果有此標記會顯示發現屍體
	- 'focus', //通過視野功能再次遇敵時獲得 bid為視野中的對象id
	- 'team', //發現隊友時獲得 bid為隊友id
	- 'neut', //發現中立單位時獲得 bid為中立單位id
	- 'chase', //追擊NPC敵人時獲得 bid為被追擊單位id
	- 'pchase', //被NPC敵人追擊時獲得 bid為追擊單位id
	- 'dfight', //與NPC敵人纏鬥時獲得 bid為纏鬥對象id
	- 'cover', //通過協戰夾擊敵人時獲得 bid為敵人id，協戰者id保存在自己身上
	- 'pcover', //被敵人的協戰者夾擊時獲得 bid為敵人協戰者的id
	- 'back', //逃跑
	- 'changewep', //切換副武器
- 檢查是否遇敵、敵人是否死亡、敵人是否處於當前地圖；
- 調用 fetch_playerdata_by_pid($enemyid) 拉取敵人數據；
- command 為 'changewep' 時，調用 change_subwep() 切換副武器；
- command 為 'back' 時，調用 escape_from_enemy($data,$edata) 判斷是否成功逃跑；
- command 為 'cover' 時，檢查是否存在協戰對象；
	- 協戰對象的 pid 保存在主視角 clbpara['coveratk'] 內；
	- 調用 fetch_playerdata_by_pid($cid) 拉取協戰對象數據；
	- 協戰對象存在時，為協戰對象添加標記 $cdata['is_coveratk'] = 1 ，以表示這是一次協戰攻擊；
- 根據 action 或 command 判斷是否需要調用 calc_active_rate($data,$edata) 重新計算先攻概率；
- 根據先攻情況調用 \revcombat\rev_combat_prepare($data,$edata,1) 或 \revcombat\rev_combat_prepare($edata,$data,0) 轉入戰鬥準備流程；

戰鬥準備流程 rev_combat_prepare()：
- 根據傳入的 $wep_kind 判斷主視角（玩家）是否主動發動了戰鬥技，將戰鬥技id保存在 $pa['bskill'] 內；
- 根據傳入的 $active 判斷主視角與敵對視角稱謂，保存在 $pa['nm'] 與 $pd['nm'] 內；
- 調用 get_attr_wepbase($pa,$pd,$active,$wep_kind) 初始化雙方攻擊相關參數，按下列次序依次判定：
	- 防守方防守方式 \revattr\get_wep_kind($pd) 保存在 $pd['wep_kind'] 內; 
		- 沒有子彈的槍械 保存為 $pd['is_wpg']
	- 防守方被動技能參數 \revattr\get_attr_passive_skills($pd,$pa,$active);
		- 所有標籤為 'passive','buff','inf' 且滿足瞭解鎖條件的被動技能都會自動激活 保存為 $pd['skill_技能ID'] 或 $pa['skill_技能ID']（下略）；
		- 標籤為 'switch' 的被動技能僅在技能開啓時激活 保存為 $pd['askill_技能ID'] ；
		- 如果技能觸發時存在log，保存在 $pd['skilllog'] 內，進入打擊流程後，在 $pa['bskilllog'] 與 $pa['bskilllog2'] 顯示後顯示；
	- 防守方武器射程 $pd['wep_range'] = \revattr\get_wep_range($pd);
	- 防守方攻擊熟練度 $pd['wep_skill'] = \revattr\get_wep_skill($pd);
	- 防守方武器名 $pd['wep_name'] = $pd['wep'];
	- 進攻方攻擊方式 \revattr\get_wep_kind($pa,$wep_kind,$pd['wep_range']); 
	- 進攻方主動技能參數 \revattr\get_attr_bskills($pa,$pd,$active);
		- NPC敵人會隨機釋放滿足了條件的戰鬥技；
		- 主動技默認log保存在 $pa['bskilllog'] 內，在進入打擊流程後顯示；
		- 主動技額外log可以保存在 $pa['bskilllog2'] 內，會在 $pa['bskilllog'] 顯示後顯示；
	- 進攻方被動技能參數 \revattr\get_attr_passive_skills($pa,$pd,$active);
	- 進攻方武器射程 $pa['wep_range'] = \revattr\get_wep_range($pa);
	- 進攻方攻擊熟練度 $pa['wep_skill'] = \revattr\get_wep_skill($pa);
	- 進攻方武器名 $pa['wep_name'] = $pa['wep'];
- 進入戰鬥流程；

戰鬥流程 rev_combat()：
- 打擊開始前，調用 combat_prepare_events($pa,$pd,$active) 執行整場戰鬥只會觸發一次的事件；
	- 返回值小於0時 跳轉至 battle_finish_flag 跳過打擊階段；
- 調用 combat_prepare_logs 顯示遇敵時會觸發的文本；
- pa打擊事件；
	- 調用 rev_attack($pa,$pd,$active) 轉入 pa打擊流程 將打擊傷害保存在 $att_dmg 內；
	- 調用 rev_combat_result($pa,$pd,$active) 轉入 pa打擊結束流程 將結果保存在 $att_result 內；
		- 暴斃標識 $pa['ggflag'] 存在時，清空$pa生命，並調用 rev_combat_result($pd,$pa,$active)；
		- 打擊傷害 $att_dmg 不為空時，扣除$pd對應生命，並調用 rev_combat_result($pa,$pd,$active)；
		- pa打擊結果 $att_result 不為空時，調用 attack_check_can_loop($pa,$pd,$active) 檢查是否要循環執行打擊流程；
- pd反擊事件：
	- pd生命不為空，且 $att_result 不為空時，調用 attack_check_can_counter($pa,$pd,$active) 檢查是否轉入反擊流程；
		- 不能反擊的原因保存在 $pd['cannot_counter'] 內；不能反擊的log保存在 $pd['cannot_counter_log'] 內；
		- 判斷是否因固定原因無法反擊；
		- 調用 calc_counter_range($pa,$pd,$active) 判斷是否因射程不足無法反擊；
		- 調用 calc_counter_rate($pa,$pd,$active) 判斷是否達到反擊率；
	- 反擊流程：重複pa打擊事件流程；
		- 反擊時，添加標記 $pd['is_counter'] = 1 ，以表示這是一次反擊攻擊；
- 更新全局戰鬥情報階段，調用 save_combatinfo() 保存當前最高傷害者等信息;
- logsave階段；
	- 在打擊流程中觸發的需logsave的文本，可以保存在 $pa['logsave'] 或 $pd['logsave'] 內，在此時一併輸出，順序為：
		- 手持 *** 的 *** 向你襲擊；
		- $pa['logsave']；
		- 你升級了；
		- 你受到其 *** 點攻擊，對其作出 *** 點反擊；
- 戰鬥收尾階段(battle_finish_flag)，根據戰鬥結果更新 action ；
	- pd死於戰鬥，$pa['action'] = 'corpse'; pa死於戰鬥，$pd['action'] = 'pacorpse';
	- 協戰標記 ['coveratk_flag'] 存在時，['action'] = 'cover'; ['clbpara']['coveratk'] = ['coveratk_flag'];
	- pa或pd均不是當前玩家時，將 action 臨時保存在 $saction 內， 將 bid 臨時保存在 $sid 內；
- 調用 init_battle_rev($pa,$pd,1) 或 init_battle_rev($pd,$pa,1) 刷新界面；
- 調用 player_save($pa) player_save($pd) 將雙方數據保存回數據庫；
- pa或pd均不是當前玩家時，説明此次戰鬥流程沒有玩家參與，引入$pdata作為玩家數據；否則調用 fetch_playerdata_by_name() 重新從數據庫中讀取回玩家數據；
- 存在臨時動作 $saction 與 $sid 時 將其保存回玩家 action 與 bid 內；
- 顯示戰鬥結果；
	
打擊流程 rev_attack()：
- 調用 \revattr\get_equip_ex_array($pa)與($pd) 獲取防具上屬性信息，分別保存在 $pa['ex_equip_keys'] 與 $pd['ex_equip_keys'] 內（pa/pd下略）；
- 調用 \revattr\get_get_wep_ex_array() 獲取武器上屬性信息，保存在 ['ex_wep_keys'] 內；
- 進行三抽判定，分別保存為 (技抽)['skdr_flag'] (魂抽)['sldr_flag'] (精抽)['mdr_flag']；
- 合併武器、防具屬性信息，保存在 ['ex_keys'] 內；
- 調用 \revattr\get_extra_ex_array() 獲取不受三抽影響的額外屬性信息，一併保存在 ['ex_keys'] 內；
- 調用 \revattr\hitrate_prepare_events($pa,$pd,$active) 執行命中前事件；
	- 返回值小於0時，直接中斷打擊流程；
- 調用 \revattr\get_hitrate_rev($pa,$pd,$active) 獲取 pa基礎命中率 保存在 $pa['hitrate'] 內；
- 調用 \revattr\get_hit_time_rev($pa,$pd,$active) 獲取 pa命中次數、武器損耗次數、致傷次數；
	- 實際命中次數保存在 $pa['hitrate_times'] 內；
	- 理論最大命中次數保存在 $pa['hitrate_max_times'] 內；
	- 武器損耗次數保存在 $pa['wep_imp_times'] 內；
	- 致傷（敵人防具損傷）次數保存在 $pa['inf_times'] 內；
- 輸出打擊前log、$pa['bskilllog']、$pa['bskilllog2']、$pa['skilllog']；
- 總命中次數大於0時：
	- 調用 \revattr\get_fix_damage($pa,$pd,$active) 檢查是否存在不受任何係數變化影響的固定傷害（直死、混沌傷害等）；
		- 固定傷害結果不為NULL時，將固定傷害保存在 $pa['final_damage'] 內，並結束傷害計算；
	- 固定傷害不存在時，正常計算傷害：
	
		- 物理傷害計算階段：
			- 調用 \revattr\get_base_att($pa,$pd,$active) 獲取 pa基礎攻擊力 保存在 $pa['base_att'] 內；
				- 武器實際效果（空手、沒子彈的槍）保存在 $pa['wepe_t'] 內；
			- 調用 \revattr\get_base_def($pa,$pd,$active) 獲取 pd基礎防禦力 保存在 $pd['base_def'] 內；
			- 調用 \revattr\get_original_dmg_rev($pa,$pd,$active) 計算原始傷害 保存在 $pa['original_dmg'] 內；
			- 調用 \revattr\get_original_fix_dmg_rev($pa,$pd,$active) 計算在原始傷害基礎上附加的固定傷害（重槍、靈武固傷）；
			- 調用 \revattr\get_damage_p_rev ($pa,$pd,$active) 計算傷害倍率的變化（連擊、必殺、靈武係數） 返回的是一個數組 ；
			- 調用 \revattr\deal_damage_prepare_events($pa,$pd,$active) 執行攻擊方(pa)在造成傷害前觸發的事件 （檢查pd身上是否有防禦屬性，pa是否觸發了貫穿、衝擊）；
				- 觸發衝擊時，$pa['charge_flag'] = 1；
				- 觸發傷害抹消時，$pd['phy_def_flag'] =  2;
				- 觸發全系防禦時，$pd['phy_def_flag'] =  1;
				- 觸發單系防禦時，$pd['phy_def_flag'] = $def_kind[$pa['wep_kind']];
				- 觸發貫穿時，$pa['pierce_flag'] = 1; $pd['phy_def_flag'] = 0;
			- 調用 \revattr\get_damage_def_p_rev($pa,$pd,$active) 根據防守方的技能、屬性計算傷害倍率的變化，返回結果與之前的傷害倍率數組合並；
			- 以(AxBxC=D)的格式隊列輸出物理傷害，並將總物理傷害保存在 $pa['phy_damage'] 內；
			
		- 預受傷階段，調用 \revattr\get_hurt_prepare_events($pa,$pd,$active) 提前計算 pd是否受傷、防具是否破損，但不會真正應用受傷效果；
			- 受傷情況保存在 $pd['inf_hurt'][受傷部位] 內；
			- 防具受損情況保存在 $pd['armor_hurt'][防具部位] 內；
			
		- 屬性傷害計算階段：
			- 調用 \revattr\get_base_ex_att_array($pa,$pd,$active) 獲取攻擊方能造成的屬性傷害隊列 保存在 $pa['ex_attack_keys'] 內；
			- 調用 \revattr\deal_ex_damage_prepare_events($pa,$pd,$active) 獲取攻擊方在造成屬性傷害前觸發的事件（檢查pd身上是否有防禦屬性，pa是否觸發了屬穿）
				- 觸發屬性抹消時，$pd['ex_def_flag'] =  2;
				- 觸發屬性防禦時，$pd['ex_def_flag'] =  1;
				- 觸發破格時，$pa['ex_pierce_flag'] = 1; $pd['ex_def_flag'] = 0;
			- 調用 \revattr\get_original_ex_dmg($pa,$pd,$active) 獲取原始屬性傷害隊列；
				- 屬性傷害被抹消或護盾抵消時，只返回單個數值；否則遍歷能造成屬性傷害的隊列，並返回一個記錄有每個屬性造成了多少傷害的數組；
				- 計算單個屬性基礎傷害，保存在 $ex_dmg 內；
				- 計算得意武器對屬性基礎傷害的修正；
				- 調用 get_ex_base_dmg_max($pa,$pd,$active,$ex,$ex_dmg) 計算單個屬性的基礎傷害上限；
				- 計算屬性基礎傷害浮動；
				- 調用 get_ex_base_dmg_p($pa,$pd,$active,$ex,$ex_dmg) 計算單個屬性傷害的係數變化；
					- 已經處於**異常狀態時，**屬性傷害** 的log 保存在 $pa['ex_dmgpsh_log'] 內；
					- 屬性傷害被**防禦了 的log 保存在 $pa['ex_dmgdef_log'] 內；
					- 成功施加了**異常 的log 保存在 $pa['ex_dmginf_log'] 內；
				- 將單個屬性傷害 $ex_dmg 加入總隊列 $total_ex_dmg[] 內；
			- 調用 \revattr\get_ex_dmg_p($pa,$pd,$active) 獲取對總屬性傷害的倍率修正；
			- 以(AxBxC=D)的格式隊列輸出屬性傷害，將最終造成的屬性傷害保存在 $pa['ex_damage'] 內；
			
		- 最終傷害計算階段：
			- 調用 \revattr\get_final_dmg_p($pa,$pd,$active) 計算最終傷害的係數變化；
			- 調用 \revattr\get_final_dmg_fix($pa,$pd,$active,$damage) 計算最終傷害的定值變化（附加傷害、傷害制御、純粹傷害、秒殺等）；
			- 如果最終傷害不存在定值變化，則輸出一段 AxBxC=D 格式的文本；
			- 如果最終傷害存在定值變化，輸出一段 實際傷害(原始傷害) 格式的文本；
			- 將造成的最終傷害保存在 $pa['final_damage'] 內；
			
		- 調用 checkdmg($pa['name'],$pd['name'],$damage) 將傷害發送至進行狀況；
		- 調用 \revattr\attack_finish_events($pa,$pd,$active) 應用pa造成傷害後觸發的事件（計算反噬傷害）；
		- 調用 \revattr\get_hurt_events($pa,$pd,$active) 應用pd受傷事件（受傷、防具受損）；
		
- 調用 expup_rev($pa,$pd,$active) 結算戰鬥經驗；
	- 升級時，將升級文本保存在 $pa['lvlup_log'] 內，在logsave時一併輸出；
- 調用 rgup_rev($pa,$pd,$active) 結算戰鬥怒氣；
- 調用 weapon_loss($pa,$pa['wep_imp_times']) 結算武器損耗；
- 調用 addnoise($pa['wep_kind'],$pa['wepsk'],$now,$pa['pls'],$pa['pid'],$pd['pid'],$pa['wep_kind'] ) 保存聲音信息；
- 為pa增加對應熟練度；
- 返回造成的最終傷害；

打擊結束流程 rev_combat_result()：
- pd生命值低於0時，結算擊殺/復活事件；
	- 結算NPC二階段變身事件；
	- 存在暴斃標記 ['gg_flag'] 時 將死亡方式 $death_flag 登記為 $pd['gg_flag'];
	- 否則將將死亡方式 $death_flag 登記為 $pa['wep_kind'];
	- 調用 pre_kill_events($pa,$pd,$active,$death_flag) 執行不需要考慮復活問題的預擊殺事件；
		- 登記死者遺言；
		- 向進行狀況及聊天框發送信息；
	- 調用 revive_process($pa,$pd,$active) 判斷是否復活；
	- 調用 final_kill_events($pa,$pd,$active,$lastword) 執行沒有復活的情況下的後續擊殺事件；
		- 增加擊殺數，降低倖存數；
		- 調用 \revattr\get_killer_rp($pa,$pd,$active) 結算rp變化；
		- 調用 check_death_events($pa,$pd,$active) 執行pd死亡後事件（靈魂綁定等）；
		- 計數相關成就；
- pd生命值不低於0，結算對應事件；
